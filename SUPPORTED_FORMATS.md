# Поддерживаемые форматы QuickPreview 1.3.10

Все обработчики работают локально. Выделите файл в Проводнике и нажмите **Space**.
Стрелки сохраняют связь с фактическим выделением и текущей сортировкой Проводника.
Направления учитывают текущий вид: ряды значков/плиток, столбцы списка и строки таблицы.
Изменение ширины или режима Проводника учитывается без повторного открытия превью.

Для файлов с визуальным и текстовым представлением доступны вкладки **Визуал**
и **Текст**: текстовые STEP/IGES/OBJ/STL/PLY и другие модели, DXF, SVG/SVGZ и
CSV/TSV. Первым открывается визуал. В 3MF/FCStd вкладка «Текст» показывает XML
модели/документа внутри контейнера. Переключение сохраняет модель и ракурс;
исходный текст не форматируется и ограничен первыми 2 МиБ. Если визуальное
представление недоступно, вкладка с исходным текстом остаётся доступной.

## Инженерам и специалистам по 3D

| Форматы | Предпросмотр |
| --- | --- |
| STEP/STP, IGES/IGS, BREP/BRP | Объёмная геометрия через локальное CAD-ядро, вращение, масштаб, рёбра и вписывание |
| STL, OBJ, 3MF, PLY, OFF, AMF | Объёмная модель; для OBJ читаются локальные материалы и текстуры |
| glTF/GLB, FBX, 3DS, DAE, WRL | Модель и поддерживаемые материалы; внешние сетевые ресурсы не загружаются |
| FreeCAD FCSTD, Rhino 3DM, IFC, BIM | Модель через встроенные импортёры |
| DXF, DWG | 2D-план пространства модели: линии, дуги, окружности, полилинии, сплайны, блоки, текст и поддерживаемые границы |
| GCODE/GCO, NC, KiCad PCB/SCH, SPICE/CIR и другие текстовые инженерные файлы | Текст команд или исходных данных |

В 3D-просмотре перетаскивание вращает модель, колесо меняет масштаб.
**Вписать** восстанавливает автоматическое кадрирование при изменении окна;
**Рёбра** включает контуры. Модель после ручного перемещения сохраняет выбранный ракурс.

DWG/DXF показываются как 2D-план, без полного воспроизведения листов, 3D-тел,
прокси-объектов и всех специальных сущностей AutoCAD. Число пропущенных объектов
отмечается в заголовке. Для проприетарных форматов, например SLDPRT/SLDASM,
используется настоящий системный эскиз, если он предоставлен установленным обработчиком Windows.

| DOCX/DOCM/DOTX/DOTM | Текст Word |
| XLSX/XLSM/XLTX/XLTM | Табличная сетка, листы, объединения, ширины столбцов, высоты строк, основные стили, числа и даты |
| XLS/XLT | Табличная сетка, листы, объединения, размеры и выравнивание; шрифты и заливки упрощены |
| PPTX/PPTM/PPSX/PPSM/POTX/POTM | Текст слайдов в порядке презентации |
| DOC/DOT, PPT/PPS/POT | Текст через установленный системный фильтр Windows |
| ODS/OTS | Табличная сетка с листами, объединениями и основными стилями OpenDocument |
| ODT/OTT, ODP/OTP | Содержимое документов OpenDocument |
| CSV, TSV | Таблица с заголовками, поддержкой кавычек, многострочных ячеек, запятой/точки с запятой/табуляции |
| RTF | Читаемый текст документа |
| EML, MSG | Отправитель, адресаты, тема, тело и список вложений |
| EPUB | Текст глав в порядке книги |
| ICS/IFB, VCF/vCard | События календаря и контактные данные |

Office-просмотр показывает содержимое, а не точную печатную вёрстку, диаграммы и
встроенные изображения. Макросы и формулы не выполняются, ссылки и вложения
автоматически не открываются. Защищённые документы требуют открытия в офисном приложении.

Таблицы показывают сохранённые результаты формул; при отсутствии результата доступен текст формулы.
Форматы Excel сохраняют масштаб единиц (например, тысячи и миллионы), отдельное
представление нуля и отрицательных чисел, проценты, ведущие нули, месяцы, время
и длительности, включая систему дат 1904 года. Неверный или неподдерживаемый
формат заменяется исходным сохранённым значением без добавления единиц измерения.
Есть масштаб, вписывание по ширине, прокрутка и выбор листа. Быстрый просмотр ограничен
30 листами, 200 строками и 80 столбцами на лист, 20 000 прочитанными ячейками и 500 000 символов;
об усечении сообщает строка состояния. Бинарные XLS/XLT ограничены 32 МБ.
Диаграммы, изображения, условное форматирование и точная печатная вёрстка требуют офисного приложения.

| Форматы | Предпросмотр |
| --- | --- |
| SQLite DB/DB3/SQLITE/SQLITE3 | Схема и первые строки обычных таблиц; только чтение, без выполнения представлений и расширений |

| PCAP, PCAPNG, CAP | Заголовки, пакеты, протоколы и доступные адреса отправителя/получателя |
| ISO/IMG с ISO9660/Joliet | Метка тома и список корневых файлов/папок без монтирования |
| EXE, DLL, SYS, OCX, CPL и другие PE | Архитектура, секции, импорты и доступные сведения о версии; файл не запускается |
| CER/CRT/DER/PEM/PFX/P12/P7B/P7C | Открытые метаданные X.509, сроки, отпечатки; закрытые ключи не показываются |
| JSON/JSONL/NDJSON, XML/XSD/XSL, YAML/YML, TOML, INI/CONF/CONFIG, REG и ENV | Текст, форматирование JSON/XML, корректное чтение Unicode |
| Dockerfile, Makefile, Jenkinsfile, Terraform/HCL/TFVARS, systemd SERVICE/TIMER, Git-конфигурация | Текст конфигурации |
| C/C++/C#/F#/VB, Java/Kotlin/Swift, JavaScript/TypeScript, Python/Ruby/PHP/Go/Rust, Dart/Lua/Perl/R/Julia, SQL и другие исходники | Исходный код |
| HTML/CSS/SCSS, Vue/Svelte/Astro, GLSL/HLSL/WGSL, shell/PowerShell/BAT/CMD | Исходный текст без выполнения |
| Markdown/RST/AsciiDoc/TeX, LOG, DIFF/PATCH, SRT/VTT/ASS | Исходный текст |
| Любой другой бинарный файл | Системный эскиз, если доступен; иначе ограниченный hex-просмотр с байтами и текстовым представлением |

Автоопределение текста поддерживает UTF-8, UTF-16 и UTF-32, включая BOM.
Для известных текстовых файлов предусмотрено чтение Windows-1251. Неоднозначные
расширения вроде TS/MTS и NC дополнительно проверяются по содержимому.
XML не допускает DTD и вложенность глубже 128 уровней. Это ограничение действует
также для XML внутри Office/OpenDocument, EPUB и SVG. Обычный XML при отказе
форматирования остаётся доступен как исходный текст; контейнеры с недопустимым XML
не обрабатываются дальше.

Для быстрого отклика предпросмотры ограничены размером файла, объёмом чтения,
числом строк/сущностей и временем. Интерфейс сообщает, когда показана только часть
содержимого. Растровые изображения, эскизы папок и DWG/DXF обрабатываются в отдельном процессе;
переключение файла отменяет незавершённую обработку.

### Ограничения ресурсов

Обычный растр (PNG, JPG/JPEG, BMP/DIB, GIF, TIFF, ICO и WDP)
ограничен 64 Мп и 32 768 пикселями по стороне исходника. Результат ограничен
16 Мп и 16 384 пикселями по стороне: небольшие изображения сохраняют исходное
разрешение, крупные уменьшаются с отметкой в строке состояния. Учитывается EXIF Orientation;
для ICO выбирается самый большой кадр, у остальных многостраничных/анимированных
растров показывается первый кадр. Дизайнерские и RAW-форматы используют отдельный
быстрый рендер с длинной стороной до 2400 пикселей. Файлы изображений и DWG/DXF
ограничены 256 МиБ; декодирование имеет таймаут 20 секунд, эскизы папок — 2 секунды.

Предпросмотр папки сканирует не более 4096 записей с бюджетом перечисления
1,5 секунды и показывает до 24 отсортированных записей. При усечении появляется
пояснение. Перечисление, чтение метаданных и автономная навигация выполняются
одним фоновым обработчиком с ограниченным ожиданием. Зависший вызов файловой
системы не блокирует интерфейс и не создаёт очередь новых обработчиков;
недоступные сведения заменяются сообщением об отсутствии данных.

3D-превью ограничено 500 тысячами треугольников, 1,5 млн вершин,
1000 экземплярами объектов/материалов и бюджетом текстур 32 МиБ / 16 Мп.
Буфер 3D-рисования ограничен 1920×1080 пикселями и DPR 1,5; размер окна
и чёткость интерфейса не ограничиваются. Рёбра для моделей более 100 тысяч
треугольников отключены. Превышение бюджета показывает понятный отказ,
полный файл можно открыть в профильном приложении.

Неподвижная модель рисуется только при изменениях. Загруженный визуал
приостанавливается на вкладке «Текст» и при сворачивании, сохраняя камеру;
незавершённая загрузка при сворачивании отменяется и возобновляется при
восстановлении. Декодеры изображений/2D CAD работают отдельным процессом
с пониженным приоритетом, ограничением CPU до 25% при поддержке Windows,
таймаутом и лимитом памяти. Импорт всё равно требует ресурсов; произвольные
CAD-файлы и оборудование не имеют гарантированного времени обработки.

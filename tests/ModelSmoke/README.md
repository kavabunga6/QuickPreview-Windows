# Offline 3D and CAD checks

Requires Windows 10/11, .NET 6 SDK, and the Edge WebView2 Runtime. Run on an
interactive Windows desktop; a restricted sandbox may prevent the WebGL GPU
process from starting.

```powershell
dotnet run --project tests/ModelSmoke/ModelSmoke.csproj -c Release
```

Generates original STL, OBJ, 3MF, STEP, and IFC cube fixtures and loads each through
the production resource bridge and bundled browser renderer. The STEP fixture is
a complete AP203 advanced BREP with six planar faces, tessellated by real OCCT
WebAssembly. Each format must produce one or more meshes and exactly twelve
triangles. The original Rhino 3DM cube is committed under `fixtures/` and can be
regenerated by the optional `CreateRhinoFixture.cjs` maintainer script; Node is
not required to run the smoke tests. No model is represented by an icon or a
wireframe approximation.

Checks unchanged input files, material/texture manifest boundaries, blocked
network requests, working fit/edges controls, and aligned controls in light/dark
themes at 1000 and 520 pixels, including 125% text scaling. Browser captures go to the ignored `screenshots/`
directory. Fixtures and browser profile are generated under ignored `bin/`.

All eight corners of the model's actual world-space bounds are projected through
the current Three.js render camera and must remain inside the visible frustum.
The test also sends a wheel event to the canvas, checks that resizing preserves
the user's deliberate zoom, and verifies that Fit restores automatic framing.

The test initializes its own WPF Application and never runs QuickPreview startup,
installs keyboard hooks, or changes startup settings. Third-party distribution
provenance and licenses are in `../../assets/model-viewer/THIRD-PARTY-NOTICES.md`.

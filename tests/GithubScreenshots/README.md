# GitHub screenshot gallery

```powershell
dotnet run --project tests/GithubScreenshots/GithubScreenshots.csproj -c Release
```

Run on an interactive Windows desktop with WebView2 installed. The generator
creates its own WPF preview and neutral backdrop, then captures the complete
native window, including embedded PDF, spreadsheet and 3D views. Each capture
must remain inside its monitor; capture stops if any visible window overlaps it.

All input files are generated by [DemoFixtures.cs](DemoFixtures.cs): an original
STL turbine, STEP bracket, XLSX inventory, PDF guide, ZIP package, JSON settings,
PNG artwork and Word brief. Values and names are fictional, and timestamps are
fixed. No input paths can be supplied and no existing user documents are read.
The installed application, startup preferences and global keyboard hooks are
not used by this capture process.

Nine PNG files are written to [assets/screenshots](../../assets/screenshots).
An ignored `artifacts/manifest.json` records the demo filenames, input hashes,
image hashes, themes and pixel dimensions; original demo inputs are checked
for modification after each preview. Generated files and browser profiles stay
in the ignored build output.

The screenshots show the actual application. No UI overlays, replacement
content, compositing or post-processing are applied.
